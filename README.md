# 📝 Simple Blog Website

A clean, multi-page static blog website template built with pure HTML and CSS.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## ✨ Features

- 📄 **Multi-Page Layout** — Home, About, Blog, Contact
- 📱 **Responsive Design** — Mobile-friendly
- 🎨 **Clean Typography** — Easy to read
- 📝 **Blog Cards** — Article previews
- 🔗 **Navigation** — Easy page linking

## 📄 Pages

| Page | Description |
|------|-------------|
| index.html | Home/landing |
| about.html | About section |
| blog.html | Blog listing |
| contact.html | Contact info |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/RaulAbakarov/SimpleBlogWebsite.git
cd SimpleBlogWebsite

# Open in browser
open index.html
```

## 📁 Structure

```
SimpleBlogWebsite/
├── index.html      # Home page
├── about.html      # About page
├── blog.html       # Blog listing
├── contact.html    # Contact page
└── css/            # Stylesheets
```

## 🎨 Design Features

- Minimalist layout
- Card-based blog posts
- Fixed navigation
- Footer with links
- Hover animations
